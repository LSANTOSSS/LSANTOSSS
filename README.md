## Projetos em destaque

### SAF — System Analysis Framework · v1.0 Stable

Framework público para Engenharia de Requisitos e Análise de Sistemas, estruturado em torno do **MER — Método de Engenharia de Requisitos**.

O SAF demonstra descoberta, análise, rastreabilidade, regras de negócio, validação humana e aplicação do método em três casos fictícios e independentes.

**Competências:** Systems Analysis · Requirements Engineering · Functional Documentation · Traceability · AI Governance

[Explorar SAF](https://github.com/LSANTOSSS/SAF)

### DocFlow · v1.0 Stable CLI

CLI clean-room em Python para transformar Markdown estruturado em documentos **DOCX, HTML e PDF**, com validação, templates reutilizáveis, composição YAML, testes E2E, empacotamento e GitHub Actions.

**Competências:** Python · CLI · Document Automation · Testing · Packaging · CI/CD

[Explorar DocFlow](https://github.com/LSANTOSSS/docflow)

## Como os projetos se conectam

```text
Demanda incompleta
       ↓
      SAF
Análise + MER + rastreabilidade
       ↓
Especificação estruturada
       ↓
    DocFlow
Validação + automação documental
       ↓
 DOCX · HTML · PDF
```

O **SAF** representa a camada de análise e requisitos. O **DocFlow** representa a camada de tooling e automação. Juntos, demonstram uma linha de trabalho que vai da compreensão do problema até a geração de entregáveis verificáveis.
